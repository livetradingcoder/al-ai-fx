**3. Mail transport switched Mailgun → Resend.**
Mailgun was never actually provisioned (`MAILGUN_API_KEY`/`MAILGUN_DOMAIN`
were still Coolify placeholders). Swapped to Resend instead — reuses a
sending stack already proven elsewhere (verified 10/10 mail-tester result
on a dedicated subdomain on a different project). `src/lib/mail.ts`'s
`client` now calls Resend's REST API (`RESEND_API_KEY`, Bearer auth, JSON
body). Every sender function (`sendWelcomeEmail`,
`sendPurchaseConfirmationEmail`, `sendCompileReadyEmail`,
`sendCompileFailedEmail`, `sendResetPasswordEmail`,
`sendAdminCompilerAlertEmail`, `sendSubscriberWelcomeEmail`) is unchanged
— same `client.send(...)` shape. **`RESEND_API_KEY` is the new env var to
set in Coolify; `MAILGUN_API_KEY`/`MAILGUN_DOMAIN` are dead, can be
removed from Coolify env whenever.**

new build, logs show `[Mail] RESEND_API_KEY not set. Emails will not be
sent.` — expected no-op, not a crash.
