## Storage architecture (post-Vercel-Blob)

- `src/lib/object-storage.ts` — S3 client (MinIO), env: S3_ENDPOINT
  (http://minio-f0so0ok8skw4s0wk884kkck4:9000), S3_ACCESS_KEY_ID
  (alaifx-admin), S3_SECRET_ACCESS_KEY, S3_BUCKET (al-ai-fx).
- Encrypted sources: `sources/<slug>/v<N>.mq5.enc` (AES-256-GCM, immutable).
  Upload: `node scripts/upload-robot-source.js <slug> <path.mq5> [version]`
  (run inside the app container: `docker cp` the file in, then `docker exec`).
  goldbot v1 = GoldBot DoubleRange Hidden Broker1 (uploaded 2026-07-20).
- Compiled builds: daemon POSTs `fileDataBase64` to `/api/compiler/complete`;
  the SERVER uploads to `compiled/AL-ai-FX_<slug>_<jobId>.ex5` and stores the
  KEY in `Compilation.downloadUrl`. Legacy https downloadUrls answer 410.
- Windows VM daemon: current deployed daemon still points at Vercel-era
  API/secret. **`visionfx-ea/autocompiler-daemon/daemon-v2.js` is the ready
  replacement** (fetches source via job.sourceUrl, posts binary inline, env:
  API_URL, COMPILER_SECRET, optional POLL_INTERVAL_MS). Deploy to
  `C:\Users\Administrator\Documents\autocompiler-daemon\daemon.js` via RDP,
  set env, restart NSSM service `al-ai-fx-daemon`.
  (10s polling is now free — self-hosted PG has no per-op billing. The old
  Prisma free tier died precisely from that polling: ~17k ops/day.)
