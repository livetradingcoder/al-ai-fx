These carry the brand name and neutral, factual taglines only — **no performance,
profit, or income claims**. Keep it that way: forex/EA promotion is heavily
restricted on ad platforms, and unsubstantiated return claims are the fastest way to
get an account banned. Use these for organic social and email, not paid forex ads.
